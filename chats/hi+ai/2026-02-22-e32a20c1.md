## 问题1：后台任务超时

**解决方案**：不通过 Claude Code 运行，直接在终端窗口执行命令。你可以打开一个 PowerShell 或 cmd 窗口，运行：

```
python "D:\dalong.com\B.MyCreate\01.AI\dalong.llm-tools\.claude\skills\yunxuetang-downloader\scripts\yunxuetang_download.py" --output-dir "C:\Users\dalong0514\Downloads\yunxuetang" run-all --courses "C:\Users\dalong0514\Downloads\yunxuetang\course_list.json" --start 0
```

只要终端窗口不关闭、电脑不休眠，就不会被终止。

## 问题2：断点续传

**当前状况**：
- **课程级别**：已支持。每完成一个课程就保存进度到 `download_progress.json`，重启后自动跳过已完成的课程。
- **视频内部**：不支持。MediaRecorder 的录制数据存在浏览器内存中（JS 的 `chunks` 数组），进程被终止后这些数据全部丢失。重启只能从头录制该视频。

**现实分析**：视频的断点续传技术上可行（定期把浏览器内存中的 chunks 保存到磁盘），但实现复杂且不稳定。更实际的做法是**确保不被终止**（用终端直接运行），这样问题1解决了，问题2就不存在了。

**总结建议**：直接在终端运行批量下载命令，不通过 Claude Code。进度文件已经确保中断后可以跳过已完成的课程继续下载。

分两步：

**第1步：获取新页面的课程列表**

```
python "D:\dalong.com\B.MyCreate\01.AI\dalong.llm-tools\.claude\skills\yunxuetang-downloader\scripts\yunxuetang_download.py" --output-dir "C:\Users\dalong0514\Downloads\yunxuetang\新目录名" list --url "新页面的完整URL"
```

这会在输出目录下生成 `course_list.json`。

**第2步：批量下载**

```
python "D:\dalong.com\B.MyCreate\01.AI\dalong.llm-tools\.claude\skills\yunxuetang-downloader\scripts\yunxuetang_download.py" --output-dir "C:\Users\dalong0514\Downloads\yunxuetang\新目录名" run-all --courses "C:\Users\dalong0514\Downloads\yunxuetang\新目录名\course_list.json" --start 0
```

**注意事项**：
- `--output-dir` 建议用不同的子目录，避免和当前下载混在一起
- `--url` 填云学堂目录页的完整 URL（包含 `catalogId` 和 `cid` 参数的那个）
- 两步之间需要**关闭 Chrome**（脚本会启动自己的 Chrome 实例）
- 进度文件 `download_progress.json` 在各自的 `--output-dir` 下独立管理
